# Privacy Policy

This service acts as a proxy between ChatGPT and Mochi Cards.

Data processed:
- Deck identifiers
- Card identifiers
- Card content submitted by the user

Data storage:
- The service does not permanently store user data.
- Requests are forwarded to Mochi Cards and processed in memory.

Authentication:
- API keys are used only for request authentication.
- API keys are never shared with third parties.

Third-party services:
- Mochi Cards (https://mochi.cards)
